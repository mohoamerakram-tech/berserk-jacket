### MODULE A: ULTRA-LOW-LATENCY 60-FRAME CANVAS SCRUBBER ENGINE (`DynamicSequenceScrubber.tsx`)
Build an interactive canvas component that turns a 60-frame WebP sequence into a zero-lag interactive scrubber driven by cursor position and touch.

Performance Architecture Requirements:
1. Instant First Frame Boot:
   - Frame 01 paints in ~20ms. The canvas fades in immediately without blocking on remaining frames.
2. Runway Buffer Preload (Frames 2-8):
   - As soon as Frame 01 renders, immediately fire parallel requests for frames 2 to 8 so initial mouse hovering never hesitates.
3. Keyframe Stride (Every 4th Frame):
   - Concurrently fetch evenly spaced keyframes across the timeline (11, 15, 19, 23, 27, 31, 35, 39, etc.). Guarantees an accurate frame is ready across 0% to 100% scrub position within ~150ms.
4. Interactive On-Demand Priority Boost:
   - If the user scrubs to frame `f` and it is not yet loaded, boost frame `f` and neighbors (`f-1`, `f+1`) with highest download priority.
5. Nearest-Neighbor Fallback with Repaint Guard:
   - While downloading, paint the closest loaded frame. If a fallback was painted, track `lastDrawnImgRef` and instantly repaint the exact frame the millisecond it finishes loading.
6. Zero-Rerender DOM Progress Bar:
   - Do NOT store loading percentage in React state. Update the DOM element directly via a `ref` (`progressBarRef.current.style.width = ...`) to eliminate 120+ unneeded React re-renders.
7. Hardware-Accelerated Context:
   - Initialize 2D canvas context with `{ alpha: false, desynchronized: true }` at native resolution (e.g. 960x540).
8. Cursor & Touch Scrubbing with Inertial GSAP Rewind:
   - Track horizontal ratio (0.0 to 1.0) on `pointermove` and draw frames via `requestAnimationFrame`.
   - On `pointerleave`, trigger GSAP tween to smoothly glide the sequencer back to Frame 0 (`ease: 'power2.out'`).

### MODULE C: INTERACTIVE MULTI-LAYER GARMENT EMBROIDERY STUDIO (`/custom-studio`)
Build a client-side garment customization suite at `/custom-studio`.

1. Two-Mode Tab Interface:
   - Tab 1 (Preset Studio): Live interactive multi-layer embroidery simulator.
   - Tab 2 (Import Bespoke): Intake form for custom vector/artwork upload, garment selection, contact details (WhatsApp/Phone), and instant reference quote generation.

2. State Model & Perspective Isolation (`lib/studio/types.ts`):
   ```typescript
   export type StudioView = 'front' | 'back';
   export type LogoSize = 'small' | 'medium' | 'large';
   export type LogoColor = 'crimson' | 'white' | 'black' | 'gold' | 'silver' | 'forest';

   export interface StudioLayer {
     id: string;          // crypto.randomUUID() — unique per placement
     logoId: string;      // references motif catalog
     colorId: LogoColor;  // thread color
     size: LogoSize;      // discrete size tier
     xPercent: number;    // 0 to 100 clamped coordinate
     yPercent: number;    // 0 to 100 clamped coordinate
   }

   export interface StudioState {
     jacketColorId: string;
     front: StudioLayer[]; // max 3 layers
     back: StudioLayer[];  // max 6 layers
   }
   ```
   *Rule: Multiple copies of the same motif must have distinct UUIDs so they move, resize, recolor, and delete completely independently. Switching front/back view must isolate layer arrays without wiping or cross-pollinating state.*

3. Freeform Pointer Dragging with Zero-Jank:
   - Handle `pointerdown`, `pointermove`, and `pointerup` on the canvas wrapper using Pointer Capture API (`setPointerCapture`).
   - Store active `draggingId` in a `useRef` to prevent re-render thrashing during drag gestures.
   - Apply `touch-action: none` so single-finger dragging on mobile does NOT scroll the viewport.
   - Clamp coordinates strictly to `3% - 97%` bounds so motifs never clip outside the garment.

4. Dynamic CSS `mask-image` Stencil Thread Recoloring:
   - Avoid heavy 3D WebGL models or pre-rendering hundreds of color combinations.
   - Provide single-color silhouette PNGs for motifs.
   - In `LogoOverlay.tsx`, render motifs using CSS mask-image stencil:
     ```tsx
     <div
       style={{
         backgroundColor: colorHex,
         WebkitMaskImage: `url(${logo.path})`,
         maskImage: `url(${logo.path})`,
         WebkitMaskRepeat: 'no-repeat',
         maskRepeat: 'no-repeat',
         WebkitMaskSize: 'contain',
         maskSize: 'contain',
         WebkitMaskPosition: 'center',
         maskPosition: 'center',
         filter: 'drop-shadow(0 2px 4px rgba(0,0,0,0.5))',
       }}
     />
     ```
   - For non-recolorable full-color artwork, fall back to standard `background-image: url(...)`.

5. Studio UI Controls:
   - Perspective Switcher (FRONT // 表 vs BACK // 裏) with active layer capacity counters.
   - Garment Base Fabric Selector (e.g. Black / White) with front and back mockup images.
   - Embroidery Motif Selector with bilingual labels.
   - Thread Color Swatch Palette with visual hex chips.
   - Discrete Size Tier Picker (Small / Medium / Large).
   - In-context Layer Toolbar / Layer List: Select, recolor, resize, and delete active layers.
   - Direct WhatsApp Quote Order button compiling active garment configuration into a pre-filled WhatsApp message.

5. CRITICAL EXECUTION & CODE QUALITY RULES
--------------------------------------------------------------------------------
1. Next.js 15/16 App Router Compliance:
   - In Next.js 15+, `searchParams` and `params` in Page components are `Promise` objects. ALWAYS `await searchParams` before accessing properties.
   - Use `'use client'` at the top of components utilizing React hooks (`useState`, `useEffect`, `useRef`).
   - Add `suppressHydrationWarning` to `<body>` in `app/layout.tsx` to ensure clean hydration.
2. Clean Fallbacks for Media Assets:
   - Never let a missing image crash the app. In `JacketPreview` and image components, attach `onError` handlers to display clean editorial placeholder boxes instructing which asset to place in `public/images/`.
3. High-Performance Canvas Standards:
   - Never call `setState` inside high-frequency `pointermove` scrubbers. Use `requestAnimationFrame` and refs.
   - Cache image objects in `imagesRef.current` to avoid redundant browser GC pauses.
4. Aesthetics:
   - Every button must feel tactile and punchy.
   - All text rendered over background imagery must use multi-layered text-shadows so it stays readable regardless of background brightness.
   - Ensure the Japanese typography and vertical margins render cleanly on desktop while elegantly collapsing on mobile screens.

Execute this specification completely with full code, zero placeholders, and strict type safety.
